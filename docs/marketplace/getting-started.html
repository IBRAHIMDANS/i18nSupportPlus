1. Install

Settings → Plugins → Marketplace, search for I18n Support Plus, click Install and restart the IDE. Works in WebStorm, IntelliJ IDEA Ultimate and PhpStorm 2025.2 or later.

2. Open your project: the setup wizard does the rest

The first time a project opens, a wizard detects its i18n framework (i18next / react-i18next, vue-i18n and Nuxt, next-intl, lingui, react-intl, ngx-translate, Transloco, svelte-i18n, i18n-js, Paraglide JS, Laravel, Symfony…), finds the translation files and proposes one module per application in a monorepo. Check the summary and click OK. Run it again at any time from Tools → i18n Support Plus → Run Setup Wizard….

3. Use it

Keys in the code are colored by status: translated in every locale, in some, in none. Hover a key to see its values, Ctrl+Click to open the translation, Shift+F6 to rename it in every locale and call site. Alt+Enter on a hard-coded string extracts it into a key written to every locale at once; one Ctrl+Z undoes the files and the code. The plugin's tool window lists the missing, empty and unused keys per locale and namespace.

4. Adjust if needed

Settings → Tools → i18n Support Plus: translation folders, namespaces and separators, the preview locale for folding and hints, machine translation engines (off by default), rules for your own translate() wrappers. Commit i18n-check.json to share the configuration with your team, and run the same checks in CI with the i18n-check command line or GitHub Action.

Other plugins

  • Coming from I18n Support, the original plugin, which no longer installs on IDEs after 2023.1: install this one next to it, it reads your project settings as they are, then uninstall the old one.
  • PO/POT files: install GNU GetText files support for full support.
  • Easy I18n and i18n Ally cover the same ground: disable them to avoid duplicated hints and gutter icons.
