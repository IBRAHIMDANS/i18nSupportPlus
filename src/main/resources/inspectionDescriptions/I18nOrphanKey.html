Reports, in a locale file, every key that the reference locale's file for the same namespace does not hold.

Example: fr/common.json holds user.nmae, en/common.json does not: a key renamed in the reference only, or a typo in the locale. The code asks for the reference's spelling, so the translation is never shown.

The reference file itself and the locales not checked for missing keys are never reported. Plural forms are compared as a group, so ru holding item_few is right when en has item_one and item_other. Quick fixes remove the key from the locale, or add it to the reference locale with an empty value.

Disabled by default. Runs in the editor and headless, in Qodana or inspect.sh.
