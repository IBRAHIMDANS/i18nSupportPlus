Reports a text written as is in the HTML of a Twig template of a Symfony project.

Example: <button>Save</button>, <input placeholder="Name">.

Off by default. The quick fix extracts the text into a key of the template's domain and writes Symfony's filter, {{ 'save'|trans }}; an echo of a value, Hello {{ user.name }}!, becomes the parameter %name% of the message. A text a tag splits, {% if %} or {% trans %}, is left alone.

Needs the Twig plugin and a composer.json requiring symfony/translation. Runs in the editor and headless, in Qodana or inspect.sh.
