Reports a string a user reads, written in JavaScript or TypeScript outside JSX: passed to a function shown to the user, or held by a property naming a caption.

Example: toast('Saved'), toast.error('Failed'), { title: 'Settings' }.

Off by default. The functions (alert, confirm, toast) and the properties (title, label, placeholder) read are options of the inspection. The quick fix extracts the string into a key.

Runs in the editor and headless, in Qodana or inspect.sh.
