Reports, in a locale file, every key of the reference locale's file for the same namespace that this file lacks.

Example: en/common.json holds user.name, fr/common.json does not: the French UI shows the key or the fallback.

The reference file itself is never reported. Plural forms are compared as a group, so ja holding item_other alone is complete. The quick fix adds the key with an empty value.

Runs in the editor and headless, in Qodana or inspect.sh.
