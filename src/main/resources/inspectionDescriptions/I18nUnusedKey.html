Reports a translation key that no code refers to.

Example: "legacy_title": "Old title" in en/common.json, with no t('legacy_title') anywhere.

Keys reached by a key prefix, an ns option, a runtime-built key (t(`status.${kind}`)) or a keep rule are not reported. Off by default: a key used only by code the plugin cannot read would be reported.

Runs in the editor and headless, in Qodana or inspect.sh.
