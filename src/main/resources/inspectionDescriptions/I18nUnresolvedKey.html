Reports a key of the code that no translation file resolves: t('common:does.not.exist').

Also reported: a namespace with no file, a missing default translation file, a key pointing at an object instead of a text, and, when Warn in code when a key is missing from some locales is on in the settings, a key some checked locales lack. A key whose call shows a default value meanwhile (t('key', 'Text')) is a weak warning.

The tooltip says how the key was read and where it was looked up. Quick fixes: create the key, create the translation file, open the settings.

Covers JavaScript, TypeScript, JSX, TSX, Vue, Svelte, Astro, PHP, Blade, Twig and Angular templates. Set its severity in the inspection profile, silence one call with // noinspection I18nUnresolvedKey, and list every unresolved key with Inspect Code, inspect.sh or Qodana.
