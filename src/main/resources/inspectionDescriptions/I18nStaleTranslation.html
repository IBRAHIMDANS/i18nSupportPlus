Reports a translation still holding the value its review was decided on, while the same key's text in the module's reference locale changed since.

Example: fr.json: "save": "Enregistrer" approved when en.json read Save, which now reads Save and close: the approval no longer holds.

Only where the module keeps reviews (an .i18n-reviews folder). The reference locale itself, and reviews decided before the source was recorded, are never reported. Approve the value again, or re-translate it, from the key dialog or the table.

Reads the review files already loaded by the IDE: no external process is run. Runs in the editor and headless, in Qodana or inspect.sh.
